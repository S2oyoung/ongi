# ongi · 온기

집 안의 기척을 읽고 분위기를 맞춰 주는 홈 IoT 동반자 **ongi**의 모바일 웹 프로토타입입니다.
Figma 디자인(온기)을 HTML · CSS · JavaScript로 옮겼고, 빌드 없이 바로 실행됩니다.

**데모:** https://s2oyoung.github.io/ongi/

## 화면 흐름

1. 온보딩 — 환영 → 테마 선택(오로라 / 화이트) → 기기 찾는 중 → 찾은 기기 → 직접 고르기 + 추가 확인 시트 → 집 알아가기 → 시작
2. 홈 — 오늘의 기척, 상태 타임라인, 분위기 저장 / 조절
3. 기척의 근거 · 분위기 저장 · 저장한 분위기(카드 / 목록) · 분위기 조절 · 설정 · 우리 집 기기

## 다양한 기기 대응

- 320px(iPhone SE 1세대)부터 430px 이상(Pro Max, 갤럭시 울트라)까지 유동 레이아웃
- `100dvh`와 `env(safe-area-inset-*)`로 노치, 다이내믹 아일랜드, 홈 인디케이터, 안드로이드 내비게이션 바 대응
- 해시 라우팅으로 안드로이드 뒤로가기와 iOS 스와이프 뒤로가기 지원
- 홈 화면에 추가(PWA 매니페스트)하면 앱처럼 전체 화면으로 실행
- 데스크톱에서는 폰 크기 프레임으로 표시

## 로컬 실행

```bash
python3 -m http.server 5178
```

브라우저에서 http://localhost:5178 를 엽니다.
